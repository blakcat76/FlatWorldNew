Font Files Required for MAUI Blazor Hybrid

The following font files need to be placed in this directory:

1. PT Sans (Cyrillic support):
   - PTSans-Regular.ttf
   - PTSans-Bold.ttf
   Download from: https://fonts.google.com/specimen/PT+Sans

2. PT Serif (Cyrillic support):
   - PTSerif-Bold.ttf
   Download from: https://fonts.google.com/specimen/PT+Serif

3. IBM Plex Mono:
   - IBMPlexMono-Medium.ttf
   - IBMPlexMono-SemiBold.ttf
   Download from: https://fonts.google.com/specimen/IBM+Plex+Mono

4. OpenSans (default):
   - OpenSans-Regular.ttf
   Download from: https://fonts.google.com/specimen/Open+Sans

After downloading, ensure all .ttf files are set with Build Action: MauiFont
in the .csproj file.
