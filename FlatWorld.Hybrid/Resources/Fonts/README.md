# Font Files for MAUI Hybrid

To use embedded fonts in the MAUI Hybrid app, download and place the following font files in this directory:

## Required Fonts

1. **PT Sans** (https://fonts.google.com/specimen/PT+Sans)
   - PTSans-Regular.ttf
   - PTSans-Bold.ttf

2. **PT Serif** (https://fonts.google.com/specimen/PT+Serif)
   - PTSerif-Bold.ttf

3. **IBM Plex Mono** (https://fonts.google.com/specimen/IBM+Plex+Mono)
   - IBMPlexMono-Medium.ttf
   - IBMPlexMono-SemiBold.ttf

## How to Add Fonts

1. Download the fonts from Google Fonts
2. Extract the .ttf files
3. Place them in this directory
4. The fonts are already registered in MauiProgram.cs

## Fallback

If fonts are not provided, the MAUI app will use system default fonts.
